# Геймдизайн — Real Life Games Enhancer

## 1. Идея в одном абзаце

Вы играете в реальную игру по настоящим правилам. Приложение — блокнот и судья: ведёт счёт, следит за ходами,
часами и подачей. Поверх — тонкий roguelike-слой: за хорошие действия игроки получают **души**, а на **Алтаре Судеб**
меняют их на **дары** (усиления) и **проклятия** (ослабления, в том числе для соперников). Каждый перк — маленькое
новое правило для конкретного игрока: «4 дротика в этом ходу», «твои кони окаменели», «говори в рифму».
Партия каждый раз немного другая — как забег в Hades или Balatro, только за кухонным столом.

## 2. Петля

```
 настоящая игра ──► событие (сотня, взятие, вышел первым) ──► души
       ▲                                                      │
       │                                                      ▼
 новое правило ◄── дар / проклятие ◄── Алтарь (колесо, пакт, сглаз, очищение)
```

Ключевые ощущения:

- **Предвкушение** — колесо крутится, сектора видны, тикает храповик.
- **Агентность** — пакт даёт выбор из 3 даров; сглаз — выбор цели.
- **Социальная драма** — проклятия на соперника, «голос робота», «обет молчания». Семья смеётся — это успех.
- **Справедливость** — отстающие получают помощь, лидер — давление. Никто не «улетает» в недосягаемость.

## 3. Экономика душ

### 3.1 Доход по играм

| Игра | За что души | Сколько |
|---|---|---|
| Дартс | 60+ / 100+ / 140+ / 180 за ход | 1 / 2 / 3 / 5 |
| | каждый бык (25 или 50) | +1 |
| | конец раунда, последнее место | +1 (фора) |
| Шахматы | взятие: пешка / конь, слон / ладья / ферзь | 1 / 2 / 3 / 5 |
| | потеря фигуры («месть»): конь, слон, ладья / ферзь | 1 / 2 |
| | шах (раз за ход), рокировка / превращение | 1 / 3 |
| Дурак | вышел первым / вторым (4+ игроков) | 2 / 1 |
| | стал дураком («утешение») | 1 |
| Пинг-понг | каждые 3 очка подряд | 1 |
| | отставание на 4+ (раз за партию) | 1 |
| | победа / поражение в партии | 3 / 1 |
| Любая игра | лучший прирост за раунд / последнее место | 1 / 1 |

Ориентир: **≈1 душа на игрока за круг ходов**. Это позволяет посещать алтарь примерно раз в 1–3 хода — часто,
но не на каждом шагу.

**Принципы:**

- Доход считается по «сырым» действиям, а не по очкам после перков (иначе ×2 удваивает и доход → снежный ком).
- В каждой игре есть доход «за проигрыш» (утешение, месть, второе дыхание) — отстающий не выпадает из экономики.
- Перки «Жатва» (+1 к доходу ×3) и «Налог тьмы» (−1 ×2) — единственные модификаторы дохода.

### 3.2 Алтарь Судеб

| Подношение | Цена | Что даёт | Зачем |
|---|---|---|---|
| **Колесо Фортуны** | 1 | случайный исход | дешёвый азарт, объём |
| **Кровавый пакт** | 3 | выбор 1 из 3 даров (≥1 редкий гарантирован), шанс порчи 25/40/55% | контроль за цену |
| **Сглаз** | 2 (1 против лидера) | случайное проклятие сопернику | социальная механика, догонялка |
| **Очищение** | 2 | снять одно своё проклятие | страховка от «серии неудач» |

**Колесо (база, хаос «Сумерки»):**

| Исход | Вес | ≈% |
|---|---|---|
| Искра (обычный дар) | 34 | 34 |
| Знамение (редкий) | 16 | 16 |
| Чудо (эпик) | 6 | 6 |
| Божество (легенда) | 1.5 | 1.5 |
| Порча | 20 | 20 |
| Проклятие | 8 | 8 |
| Рок | 2.5 | 2.5 |
| Пустота | 8 | 8 |
| Джекпот (+3 души) | 4 | 4 |

Итого 57.5% дар, 30.5% проклятие, 12% пустота/джекпот. Ожидаемая «ценность» вращения положительная,
но риск ощутим — это и есть азарт. Сектора колеса в 3D рисуются **по реальным шансам** конкретного игрока:
что видишь — то и крутишь.

### 3.3 Рычаги баланса

| Рычаг | Механика | Эффект |
|---|---|---|
| **Место в таблице** | множитель проклятий `1.25 − 0.6·p`, редких даров `0.85 + 0.5·p` (p: 0 лидер … 1 последний) | лидер ×1.25 проклятий, последний ×0.65 и +35% к редким |
| **Милость богов** | после 2 проклятий подряд с колеса — следующее вращение без проклятий | защита от фрустрации |
| **Сглаз лидера дешевле** | −1 душа | коллективное давление на лидера |
| **Пощада** | нельзя сглазить игрока с 2+ проклятиями | никто не тонет под кучей |
| **Слоты** | 4 дара, 3 проклятия; лишнее вытесняет старое | нет бесконечного накопления |
| **Стак одинаковых** | заряды складываются, таймеры обновляются | повтор не пропадает зря |
| **Пакт: последнее место** | без цены (0% порчи) | догонялка через контроль |
| **Хаос** | Тихий омут ×0.5 проклятий; Безумие ×1.4 проклятий, ×1.8 эпиков, ×2.2 легенд | настройка под компанию |
| **Фора** | +1 душа последнему в конце раунда (дартс, любая игра) | стабильный доход отстающим |

### 3.4 Тайминг алтаря

Чтобы игра не превращалась в бесконечное «а можно я ещё покручу», алтарь открыт только в «паузы» самой игры:

- **Дартс** — только своему игроку, до первого дротика хода.
- **Шахматы** — только в свой ход. Часы при этом идут (визит к алтарю стоит времени — это часть решения).
- **Дурак** — между раундами (пока никто не вышел).
- **Пинг-понг** — между розыгрышами, любому.
- **Любая игра** — когда угодно, за честностью следит ведущий.

## 4. Перки

### 4.1 Типы

- **Авто (⚙)** — приложение применяет само: множители очков, лишние/недостающие дротики, проклятый сектор,
  щит от перебора, скорость шахматных часов, двойное очко в пинг-понге, маска шута в дураке.
- **Настольные** — правило, которое соблюдают люди: «бросай нерабочей рукой», «конь ходит как…», «молчи раунд».
  Если у перка есть заряды — в карточке игрока есть кнопка «Использовать».
- **Мгновенные** — срабатывают сразу: +души, кража душ, ±секунды на часах, буря на лидера.

### 4.2 Длительность

`instant` · `charges n` (заряды) · `ticks n` (N ходов/раундов/розыгрышей — единица берётся из игры) · `game`.
Таймеры тикают в конце хода владельца (дартс, шахматы, любая), в конце раунда (дурак), после каждого розыгрыша (пинг-понг).
Перк, купленный перед своим ходом, действует уже в этом ходу.

### 4.3 Редкость и бюджет силы

| Редкость | Дар (пример) | Проклятие (пример) |
|---|---|---|
| Обычная — Искра / Порча | Щит от перебора, Рывок пешки, +2 души | Не та рука, Голос машины, −1 душа |
| Редкая — Знамение / Проклятие | ×2 очков хода, 4-й дротик, Вор времени | ÷2 очков, Ледяная вертикаль, Печать изгнания |
| Эпик — Чудо / Рок | Тройная корона, Воскрешение, Маска шута | Пустая душа, Тень ферзя, Двойной позор |
| Легенда — Божество | Метеор ×3, Двойной ход, Козырь из рукава | — |

Правило бюджета: **обычный перк меняет один бросок/ход, редкий — ход целиком, эпик — ход партии,
легенда — даёт «момент», о котором будут вспоминать**. Проклятия максимум «Рок» — без легенд, чтобы не было
ощущения «игру у меня украли».

### 4.4 Как писать перк

- Название — 1–2 слова, образ («Песочные часы», «Обет молчания»).
- Текст — одно правило, на «ты», без двусмысленности. Если спорно — решает тот, против кого перк сыгран.
- Проверка: можно ли выполнить за столом без остановки игры дольше чем на 10 секунд?
- Безопасность: никаких перков, требующих опасных действий (с закрытыми глазами — только если безопасно).

## 5. Игры

### Дартс — «Таверна „Кривой Дротик“»
X01 (301/501/701, дабл-аут опционально, лимит раундов) и «Охота» (N раундов, больше очков). Ввод: кольцо → сектор.
Подсказка закрытия (чекаут) для X01. Перебор, щит, множитель, «сгоревший» множитель — считает приложение.
3D: дротик реально летит в названный сектор мишени.

### Шахматы — «Цитадель Чёрной Королевы»
Двое. Часы (3+2 … 30), события хода (взятие по типу фигуры, шах, рокировка, превращение) → души.
Перки меняют правила ходов (конский прыжок, рывок пешки, окаменение коней) и часы (вязкое время, спешка, вор времени).

### Дурак — «Притон Шулера»
2–6 игроков, подкидной/переводной, до N поражений. Ввод: отметить, кто вышел; последний — дурак.
Маска шута отменяет поражение, «Двойной позор» удваивает.

### Пинг-понг — «Подвальная Арена»
Двое, партии до 11/21, матч до 1/2/3 побед. Приложение ведёт подачу (каждые 2 очка, при 10:10 — каждое).
«Двойное очко», «Стена», «Цунами» — авто; «Цапля», «Не та рука» — настольные.

### Любая игра — «Бездна Игр»
Универсальный блокнот: счёт ± шагами, ходы и раунды, цель, «меньше — лучше». Перки в «шагах очков».

## 6. Метрики успеха (для плейтестов)

- Каждый игрок посещает алтарь хотя бы раз за 10 минут.
- Отрыв лидера в конце партии не «улетает» по сравнению с игрой без энхансера.
- ≥1 смешной момент за партию (проклятия-действия: голос робота, рифмы, «цапля»).
- Никто не просит выключить энхансер к середине игры. Если просят — пробуем «Тихий омут».
